⚙️ Configuración del sistema centralizado

Solo necesita hacer esto una vez. Después todos los funcionarios entran directo.

1Crear el Google Sheet
Este Sheet va a ser la base de datos compartida donde todos los oficios quedan guardados en tiempo real.
Haga clic en este enlace: → sheets.new (abre Google Sheets con su Gmail)
Cuando abra, cambie el nombre del archivo de "Hoja de cálculo sin título" a:
Nombre sugerido:Registro Oficios Desembargo — Alcaldía Bello
💡 Comparta el Sheet con todos sus compañeros para que puedan ver el registro. Botón Compartir (esquina superior derecha).
Usar sin registro centralizado
2Abrir Apps Script
Dentro del Google Sheet que acaba de crear:
Haga clic en el menú:Extensiones → Apps Script
Se abre una nueva pestaña con el editor de código. Verá algo como function myFunction() {}. Borre todo ese texto y pegue el contenido del archivo codigo_apps_script.js que viene junto con este sistema.
Pasos en el editor: 1. Seleccionar todo (Ctrl+A) 2. Borrar 3. Pegar el código (Ctrl+V) 4. Guardar (Ctrl+S o el ícono 💾)
💡 El archivo codigo_apps_script.js fue descargado junto con este HTML. Ábralo con el Bloc de notas, seleccione todo y copie.
3Publicar como aplicación web
En el editor de Apps Script, en la parte superior derecha:
Haga clic en:Implementar → Nueva implementación
En la ventana que aparece: • Tipo: Aplicación web • Ejecutar como: Yo (su correo Gmail) • Quién tiene acceso: Cualquier persona • Clic en → Implementar
Google le pedirá que autorice permisos. Haga clic en "Revisar permisos", elija su cuenta Gmail, luego "Avanzado" → "Ir a [nombre] (no seguro)" → "Permitir".
Al final aparece una URL así:https://script.google.com/macros/s/AKfycb.../exec
⚠️ Copie esa URL completa — la necesita en el siguiente paso.
4Conectar el sistema
